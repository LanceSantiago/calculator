Each dashed frame below is exactly 1080×1920 (9:16). Five panels are provided — Play accepts 2–8.

To export a clean PNG of one panel:

  1. Open this file in Chrome or Edge.
  2. Press F12 to open DevTools, click the Elements tab.
  3. Find a <section class="panel"> node (or right-click the panel → Inspect).
  4. Right-click that node → Capture node screenshot. Chrome saves a 1080×1920 PNG with no dashed outline.

Repeat for each panel. You can also just edit the marketing copy inline before capturing.
